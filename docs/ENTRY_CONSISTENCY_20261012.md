# 2026-10-12 진입 정합성 및 손익 보고 개선

기준: `bdde6c228f66375717f3c1a9843dfbb9cadcd871`.
분석 자료: 2026-09-29, 09-30, 10-01, 10-02, 10-06, 10-07, 10-08 번들.

## 확인한 문제

주문가격으로 대응시킨 45건의 비용 전 추정 손익은 -343,060원이다.
누적 매수금액 267,789,055원에 왕복 비용 0.35%를 적용하면 -1,280,321.69원,
0.90%를 적용하면 -2,753,161.50원이다. 누적 매수금액은 계좌 원금이 아니다.
`accepted=True`는 주문 접수이므로 이 금액을 실제 체결 실현손익으로 해석할 수 없다.

진입 시 VWAP 아래였던 7건 중 6건이 VWAP 청산으로 이어졌다. 기존 매수 전략이
허용하는 진입 상태와 초기 청산 조건이 충돌하는 구간이다. 또한 기존 가격 재조회
허용 오차 0.5% 안에서도 VWAP를 하향 통과할 수 있다.

10월 7일 거래가 없었던 자료에서는 15시 이후 BUY 신호 5건이 시간 제한에 막혔다.
거래 횟수를 늘리기 위한 진입 제한 완화는 이번 수정에 포함하지 않는다.

## 변경

- `trading.require_entry_above_vwap: true`를 제공 YAML에 추가한다. 모든 신규 매수는
  판단 가격과 직전 재조회 가격 모두 유효한 VWAP를 초과해야 한다. 같거나 낮으면
  `ENTRY_BELOW_VWAP`, VWAP/가격/재조회 증거가 없거나 비정상이면
  `ENTRY_VWAP_UNAVAILABLE`로 차단하고 signal_log에 사유를 남긴다.
  오래된 시세·미결 주문 등 기존 앞단 검사는 유지한다. 기존 설정 파일에서 키를
  생략하면 기본값은 false이므로, 로컬 YAML을 보존해 병합할 때 true를 확인해야 한다.
- run_id별 설정 JSON에 `source_fingerprint`를 추가한다. app/config/domain/infra/utils
  내 Python 파일 및 requirements.txt의 파일별·전체 SHA-256을 기록한다. Git에
  아직 추가하지 않은 Python 파일도 대상이다. 읽기 실패와 심볼릭 링크는
  `complete=false`와 목록으로 표시한다. 소스 원문/환경변수/설정 원문 해시를
  추가 저장하지 않으며 기존 설정 비밀값 마스킹을 유지한다. CSV 헤더는 바꾸지 않는다.
- `analyze_trades.py`에서 주문 접수와 체결을 구분하고 공통 cost_model의
  Gross/Base/Stress를 함께 표시한다. 날짜별 시간순 FIFO의 동일 수량 1:1 주문쌍만
  추정하고 미대응·제외 주문 수를 표시한다. 매수 전 매도, 다른 날짜, 수량 불일치,
  잘못된 시간/가격/수량은 손익에 넣지 않는다. 부분체결 원장 대체용이 아니다.
- 일일 번들 app 로그에 ENTRY_VWAP/PRICE_REVALIDATE/EXCL 태그를 포함한다.

VWAP 검사는 진입 가능 종목을 줄일 수 있다. 수익성 개선이 검증된 전략 최적화나
체결 가격 보장이 아니다. VWAP 자체의 분봉 신선도는 기존 분봉 안전 검사에 의존한다.
파일 지문은 시작 시 디스크 파일 식별이며 로딩된 바이트코드나 설치된 모든 의존성,
루트 분석 스크립트까지 재현하는 환경 스냅샷은 아니다. CRLF/LF 차이도 다른 해시다.

## 적용 후 관측

실행 PC에는 이 작업으로 배포/재시작하지 않았다. 기존 실행 자료는 git_dirty=True여서
현재 GitHub 기준과 로컬 코드가 완전히 같다고 확정할 수 없다. 로컬 수정 사항과
websocket.max_symbols=25 등 실효 설정을 보존하며 패치를 병합해야 한다.
손절/청산/보유시간/일일 진입 횟수/주문금액/브로커 접속 설정은 이번 패치에서 변경하지 않는다.

모의 환경에서 기존 운용 설정을 보존한 채 새 설정 true 및 source_fingerprint.complete를
확인하고, 다음 세션 번들에서 아래 항목을 비교한다:

1. ENTRY_BELOW_VWAP / ENTRY_VWAP_UNAVAILABLE 건수 및 전체 매수 후보 대비 비율.
2. VWAP 청산·MIN_PROFIT_5M 청산 비중, 비용 차감 후 추정 손익, 실제 체결조회 커버리지.
3. 실행별 소스 지문/실효 설정 차이. 체결 증거 부족한 손익은 계속 추정으로 구분한다.
